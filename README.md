# Ziva Entertainment

A cinematic, responsive landing page for Ziva Entertainment, an independent media production, localization, and entertainment studio.

## Highlights

- Dark luxury visual system with sapphire, electric magenta, and gold accents
- CSS-built cinematic studio hero scene with mixing console and lighting details
- Responsive navigation with accessible mobile menu state
- Selected work, studio positioning, capabilities, and contact sections
- KableOne featured client integration with Chaali Din artwork and source link
- Scroll progress indicator, reveal animations, marquee motion, and reduced-motion support
- No image assets required for the primary experience

## Run locally

Open `index.html` directly in a browser, or serve the folder with a static web server:

```bash
python -m http.server
```

Then visit `http://localhost:8000`.
